# Autocratic Management Services Private Limited - Corporate Website

Institutional B2B Portfolio Website for **Autocratic Management Services Private Limited**, premier insurance investigation, claims verification, and anti-fraud risk management firm based in Aliganj, Lucknow, Uttar Pradesh.

## Quick Start

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
